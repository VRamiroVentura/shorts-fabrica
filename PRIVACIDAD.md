# Política de privacidad — Fabrica Rama

*Última actualización: 15 de octubre de 2026*

**Fabrica Rama** es una herramienta de uso personal de Ramiro Ventura (@ramacontable). Sirve para crear videos cortos sobre finanzas personales, economía, libros e impuestos y para publicarlos automáticamente en **sus propias cuentas** de YouTube e Instagram. No es un servicio abierto al público: nadie más inicia sesión ni conecta cuentas.

## Qué datos usa

- **Credenciales de acceso de las cuentas del propio autor** (YouTube e Instagram). Se usan solamente para subir los videos que genera la herramienta y para leer las estadísticas de esas publicaciones (vistas, me gusta, comentarios, guardados).
- **Información pública** de otros canales y sitios (títulos de videos, noticias, publicaciones públicas), que se usa como referencia para elegir los temas.

La herramienta **no recopila datos personales de terceros**, no usa cookies, no tiene usuarios registrados y no muestra publicidad.

## Dónde se guardan

- Las credenciales se guardan cifradas en los *Secrets* de GitHub Actions del repositorio y nunca se publican.
- Los videos y textos generados se publican en las cuentas del autor y se guardan en este repositorio.

## Con quién se comparten

Con nadie. Los datos no se venden, no se alquilan y no se transfieren a terceros. Solo se envían a las plataformas donde se publica (YouTube y Instagram) y a los servicios que se usan para generar el contenido (por ejemplo, la API de Google Gemini).

## Servicios de YouTube

Esta herramienta usa los **Servicios de API de YouTube**. Al usarla se aplican:

- las [Condiciones del Servicio de YouTube](https://www.youtube.com/t/terms);
- la [Política de Privacidad de Google](https://policies.google.com/privacy).

El acceso a la cuenta de Google se puede revocar en cualquier momento desde la [página de permisos de seguridad de Google](https://myaccount.google.com/permissions).

## Cómo borrar los datos

El autor puede revocar los accesos desde la configuración de cada plataforma y borrar los *Secrets* del repositorio. Al hacerlo, la herramienta deja de tener acceso a la cuenta.

## Contacto

Por consultas sobre esta política: mensaje directo a **@ramacontable** en Instagram, o un *issue* en este repositorio.

### English summary

Fabrica Rama is a personal tool used only by its author to create short videos and publish them to his own YouTube and Instagram accounts. It does not collect personal data from third parties, does not sell or share data, and stores access credentials encrypted in GitHub Actions secrets. It uses YouTube API Services; see the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy). Access can be revoked at any time at [Google security settings](https://myaccount.google.com/permissions).
